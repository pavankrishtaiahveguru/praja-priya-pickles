# 🥭 Praja Priya Pickles

A premium, modern, and fully responsive website for **Praja Priya Pickles**, showcasing authentic homemade Andhra pickles and traditional podulu. The website provides a smooth shopping experience with a cart, checkout flow, and WhatsApp order integration.

# 📦 Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to project

```bash
cd praja-priya-pickles
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build project

```bash
npm run build
```

Start production

```bash
npm start
```

# 🛒 Checkout Flow

1. Browse Products
2. Add Products to Cart
3. Review Shopping Cart
4. Enter Customer Details
5. WhatsApp Order Confirmation
6. Order Sent to Business

# 📲 WhatsApp Integration

Customers can place orders directly through WhatsApp.

The checkout automatically sends:

- Customer Details
- Delivery Address
- Ordered Products
- Quantity
- Weight
- Product Subtotal
- Delivery Charge
- Grand Total

---

# 📦 Bulk Orders

The website includes a dedicated Bulk Orders section for wholesale enquiries.

Customers can:

- Call directly
- Send a pre-filled WhatsApp enquiry
